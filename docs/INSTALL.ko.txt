Refine GitHub — Chrome / Edge 설치 안내
======================================

Chrome에 설치하기

1. 주소창에 chrome://extensions 를 입력합니다.
2. 오른쪽 위의 '개발자 모드'를 켭니다.
3. '압축해제된 확장 프로그램을 로드합니다'를 누릅니다.
4. 이 안내 파일과 manifest.json이 들어 있는 폴더(dist)를 선택합니다.
5. 이미 열려 있던 GitHub 페이지를 새로고침합니다.

Edge에서는 edge://extensions 에서 같은 순서로 설치합니다.

설정을 편하게 사용하기

- 브라우저 주소창 옆의 확장 프로그램(퍼즐 모양) 메뉴를 엽니다.
- Refine GitHub 옆의 고정 버튼을 누릅니다.
- 고정된 아이콘을 누르면 넓게 보기와 집중 모드를 바로 설정할 수 있습니다.
- 본문 글자 크기는 Page options의 Font size에서 설정합니다.
- 팝업의 ON/OFF 스위치로 모든 지원 탭에서 확장의 효과를 끄거나 다시 켭니다.
  다시 켜면 저장해 둔 설정이 적용됩니다.
- Page width에서 너비를 고르면 페이지별 예외를 해제하고 한 번에 적용합니다.
- Page options에서 공통 너비와 이슈, PR, 위키, README·Markdown, Compare·커밋 상세의
  개별 너비를 설정합니다. Compare·커밋 상세는 기본적으로 PR 너비를 따릅니다.

사내 GitHub에서 사용하기

- HTTPS로 사내 GitHub를 열고 확장 아이콘을 누릅니다.
- 표시된 호스트 이름을 확인한 뒤 Enable on this site를 누르고 브라우저에서 접근을 허용합니다.
- 같은 호스트의 지원 페이지에도 읽기 설정이 적용됩니다.
- Disable on this site를 누르면 해당 호스트의 접근 권한이 해제됩니다. 팝업 상단의 ON/OFF 스위치 왼쪽에 있는 ↺ 버튼을 누르면 읽기 설정이 초기화됩니다.

ZIP 파일로 전달받았다면

- refine-github-<버전>.zip을 먼저 원하는 위치에 압축 해제합니다.
- 압축 해제한 폴더 중 manifest.json이 있는 폴더를 선택합니다.
- 설치한 폴더는 계속 같은 위치에 보관하세요.
- ZIP 파일 자체를 Chrome에 드래그해서 설치하는 방식은 지원하지 않습니다.

개발 중 변경 사항 적용하기

- npm run build: 이 dist 폴더의 확장프로그램 파일을 갱신합니다.
- npm run package: 파일 갱신 후 release/refine-github-<버전>.zip도 생성합니다.
- chrome://extensions에서 Refine GitHub의 새로고침 버튼을 누른 뒤,
  GitHub 페이지도 새로고침합니다.
