# 읽기 설정 테스트 가이드

이 페이지는 제목, 일반 문단, 표, 코드 블록이 섞인 문서를 읽을 때 사용합니다. 위에서 아래로 한 번 읽은 다음 페이지 맨 위로 돌아와 넓게 보기를 켜 보세요. 같은 문장이 어느 단어에서 다음 줄로 넘어가는지 비교하면 본문에 쓸 수 있는 공간이 얼마나 달라졌는지 확인할 수 있습니다.

## 페이지 목록과 본문 비교

데스크톱 창에서 집중 모드를 끄면 본문 옆의 위키 페이지 목록을 함께 볼 수 있습니다. 넓게 보기를 켠 뒤에도 목록을 사용할 수 있는지 살펴보세요. 이어서 집중 모드를 켜면 목록이 차지하던 공간까지 본문이 넓어집니다. 두 설정을 하나씩 바꾸면 각각의 효과를 구분하기 쉽습니다.

## 설정 조합

| 넓게 보기 | 집중 모드 | 비교할 내용 |
| --- | --- | --- |
| 끔 | 끔 | 기본 본문 여백과 위키 페이지 목록 |
| 켬 | 끔 | 목록을 보면서 읽을 수 있는 본문의 너비 |
| 켬 | 켬 | 목록이 사라진 뒤 표와 문단의 오른쪽 경계 |

## 글자 크기와 문서 구조

글자 크기를 14px로 바꾸고 이 문단을 읽은 뒤 20px로 바꿉니다. 제목과 문단, 표가 차례대로 보이고 글자가 서로 겹치지 않는지 확인합니다. 아래는 이 문서에서 사용하는 예시 설정입니다.

```json
{
  "wide": true,
  "focus": false,
  "fontSize": 20
}
```

다른 이슈 탭으로 이동한 뒤 다시 이 페이지로 돌아옵니다. 페이지를 새로고침해도 선택한 글자 크기가 유지되는지 확인하면 비교가 끝납니다.
