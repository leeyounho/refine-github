# Refine GitHub

Refine GitHub lets you adjust page layouts and edit Markdown with a side-by-side preview on GitHub and GitHub Enterprise Server.

## Features

- Set a shared page width or choose separate widths for issues, pull requests, discussions, wikis, Markdown documents, and diffs.
- Hide sidebars with Focus mode, adjust the body text size, and set the height of writing areas.
- Edit issue bodies, comments, wiki pages, and Markdown files alongside a live preview. Scrolling either pane brings the corresponding passage into view in the other. For issues and wikis, the extension sends the draft to the current GitHub host for rendering after you pause typing.

## Permissions

- `storage` saves layout and editor preferences and remembers enabled Enterprise hosts.
- `activeTab` reads the current tab’s hostname when you open the popup so you can manage access for that site.
- `scripting` applies scripts and styles to open GitHub tabs and reads the full draft from GitHub’s code editor for the live preview.
- **Host access** enables layouts and previews on `https://github.com/*`. The optional `https://*/*` permission is requested only for the Enterprise host you enable.
